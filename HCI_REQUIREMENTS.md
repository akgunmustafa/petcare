# HCI Principles & Project Scope

## 1. Applied HCI Rules in UI
- **Emergency Mode (Fitts's Law):** Fixed, high-contrast red button on Dashboard. Max 2 clicks to summon help.
- **Cognitive Load (Miller's Law):** Dashboard uses a clean 5-card grid corresponding to the 5 core modules.
- **Trust & Transparency:** Verified badges for Vets/Sitters, Digital Vaccine Card preview before booking, and Escrow payment notice.
- **WCAG 2.1 AA Compliance:** Minimum 4.5:1 contrast ratio, accessible labels, mobile-first touch targets (min 48x48px).

## 2. Cross-Module Synergy (Key Feature)
When booking a **Pet Hotel or Sitter** (`/boarding`), the user gets a single checkbox:
`[x] Add Pet Taxi for Pickup & Drop-off`. This connects the Boarding, Taxi, and Digital Pet Card modules in one seamless user journey.
